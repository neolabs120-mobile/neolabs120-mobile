## 소개

**2018년 7월부터 프리랜서 모바일 개발자**로 활동하며 네이티브 앱 개발, 기존 코드 리팩토링, 온디바이스 AI 통합을 경험했습니다.

**효율적인 ML, 모델 압축·양자화, 모바일 시스템·센싱, 인간 중심 보안**에 관심이 있습니다.

## 연구 경험

**온디바이스 보이스피싱·스미싱 탐지**<br/>
학부 연구 인턴 · 성균관대학교 박진영 교수 연구실

- 한국어 Streaming STT와 경량 텍스트 분류 모델을 Android 앱에 통합하고, 통화 전사·SMS 입력부터 위험도 판단, 사용자 경고, 탐지 이력 저장까지 연결했습니다.
- **sherpa-onnx / Zipformer** 기반 스트리밍 파이프라인을 구현하고, **HyperCLOVA-X 0.5B → DistilKoBERT** 지식증류와 **TorchScript Lite** 내보내기를 실험했습니다.
- 별도 시험 데이터에서 student 모델의 **AUC 0.991**, teacher 모델의 **AUC 0.995**를 확인했습니다. 실제 배포를 위한 탐지 민감도 조정과 데이터 변화 대응을 후속 과제로 정리했습니다.

## 개발 경력

**프리랜서 모바일 앱 개발자** · 개인<br/>
2018.07 – 현재

요구사항 분석과 앱 기획부터 구현·출시까지 모바일 앱 개발 전반을 맡고, 기존 코드의 구조와 동작을 개선해 왔습니다.

- Retrofit2 기반 클라이언트·서버 통신 구조를 갖춘 반려견 관리용 Android 네이티브 앱을 개발했습니다.
